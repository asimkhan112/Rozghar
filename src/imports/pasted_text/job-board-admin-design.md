# Premium Job Board Admin Panel - UI/UX Design Prompt

Design a modern, production-ready Admin Panel for a Job Board platform. The admin panel must feel like a professional internal tool used daily by operations teams, recruiters, and content managers.

The design must NOT look like a generic AI-generated dashboard, Bootstrap admin template, Material UI starter kit, or standard SaaS dashboard clone.

The result should feel handcrafted by a senior product designer with strong UX thinking, exceptional information hierarchy, and polished visual details.

---

## Design Language

Use the same design system as the public website.

### Typography

Use Geist throughout.

* Headings: Geist SemiBold
* Body: Geist Regular
* Labels & Buttons: Geist Medium

### Colors

Primary:
#33A4BB

Primary Hover:
#2B8FA3

Background:
#F8FAFB

Surface:
#FFFFFF

Text:
#111827

Secondary Text:
#6B7280

Border:
#E5EAF0

Success:
#22C55E

Warning:
#F59E0B

Error:
#EF4444

The dashboard should feel calm, modern, and easy on the eyes during long work sessions.

Avoid dark mode concepts.

Avoid excessive gradients.

Avoid glassmorphism.

---

## Overall Layout

Create a premium admin experience inspired by:

* Linear
* Stripe Dashboard
* Notion
* Vercel
* Clerk

Focus on:

* Clarity
* Speed
* Discoverability
* Efficient workflows

Use generous spacing and a strong visual hierarchy.

Avoid clutter.

* Filters
* Bulk Actions
* Sorting

* Edit
* Duplicate

* Verify
* Expire
* Delete

Status Variants:

* Published

* Reported

---

## Senior Designer Instructions

Do not generate a generic admin template.

Avoid repetitive cards and predictable AI layouts.

Use thoughtful spacing, realistic content density, meaningful hierarchy, and polished interactions.

The design should feel like a real product that could be launched tomorrow and used by a professional operations team.

Quality target:

Linear-level UX, Stripe-level clarity, and production-ready implementation quality.
